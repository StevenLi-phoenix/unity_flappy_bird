# Flappy Bird maintenance handoff

## Project and rendering

Unity 6000.6.0f1; project lives in `FlappyBird/`. URP 17.6.0, Input System 1.20.0, uGUI 2.6.0. Preserve package lockfiles and Unity `.meta` files. The scene is regenerated by `Assets/Editor/BuildGame.cs`.

The original IMGUI renderer mixed clip transforms, DPI scaling, text metrics and world coordinates. Local fixes repeatedly failed at other window sizes. The lasting fix was pooled native Canvas graphics and one `ResponsiveLayout` conversion. CanvasScaler uses Expand against 1100×660; UI is centered and the world is bottom anchored. Background/ground cover actual WorldBounds; pipes spawn and recycle beyond those bounds. Use the same conversion for pointer hit testing. Never add another screen scale or use GUI.matrix.

Text must use the same font and geometry alignment for measurement and display. Measure the best-score text, then center the trophy-plus-number group. Compose bird rotation around its own center before screen scaling: wrong matrix order caused click-time teleportation.

`FlappyPresentation.cs` owns visual rendering, `UiMotion.cs` owns local animation geometry, `ArcadeFeedback.cs` owns procedural sound and bounded particles. Speaker clicks are consumed before flap handling. Best score/mute use PlayerPrefs; visual fixtures must never alter saved progress.

## Build and verification

`BuildGame.Build` creates the macOS app; `BuildGame.BuildWebGL` creates `FlappyBird/Build/WebGL`. Both run the gameplay, presentation, feedback and responsive checks first (97 native checks, 99 WebGL checks at this handoff). Run `bash scripts/build-webgl.sh` with optional `UNITY_EDITOR` override.

`node --test scripts/*.test.mjs` tests the release validator. `node scripts/check-webgl.mjs` validates a real browser bundle, relative paths, expanded template, required assets and itch.io limits. A successful Unity compile does not establish browser correctness: serve the bundle over HTTP and inspect the actual rendered game, start/retry, mute, and resize.

For desktop rendered regression, launch with `--layout-check`; it writes five window-size fixtures and exits. WebGL excludes desktop automatic screenshot writing and command-line fixture startup. Browser `Application.dataPath` is a URL, not a writable local directory.

## Lessons from this session

- Inspect installed module paths: WebGLSupport is beside `Unity.app` in the editor version directory, not under its Contents folder.
- Sandboxed `gh auth status` may report an invalid token when network access is unavailable. Confirm with a permitted real repository API call before asking for login.
- UI accessibility `setValue` on a rich-text editor may change visible text without updating the site's saved model. Verify the saved page; use real typing or the editor's HTML mode when necessary.
- Native file pickers may return stale sheet state. Inspect the underlying picker after leaving the path sheet rather than repeatedly re-entering paths.
- Keep local-build success, artifact upload, published visibility and a passing automatic GitHub deployment as separate verified states.
